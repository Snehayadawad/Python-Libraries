# Python-Libraries
 Python provides a wide range of powerful libraries that simplify programming, data analysis, machine learning, visualization, web development, and automation. This section covers commonly used Python libraries and their practical applications.
 ## 🛠️ Python Libraries & Tools Used

This project utilizes several Python libraries for data analysis, data manipulation, and visualization:

* **Pandas** – Data cleaning, manipulation, and analysis.
* **NumPy** – Numerical computations and array operations.
* **Matplotlib** – Creating charts, graphs, and visualizations.
* **Seaborn** – Advanced statistical data visualization.
* **Scikit-learn** – Machine learning algorithms and model evaluation.
* **Jupyter Notebook / Google Colab** – Interactive coding and analysis environment.

### Key Python Concepts Applied

* Conditional Statements
